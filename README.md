## 常见问题

### SNG 与 MTT 关注点有什么不同？
SNG 重点是单桌人数与开赛条件，MTT 还涉及多桌调度、淘汰和合桌；本仓库提供赛事产品与流程资料。

### 哪个文件用于理解服务端入口？
先阅读 create_game.cpp 与 GameTcp.tars，再对照玩法时序图和服务脚本。
